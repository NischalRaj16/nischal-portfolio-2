## Tech
Plain HTML, CSS and JavaScript with no build step. It uses an illustrative, glassmorphism design with original SVG illustrations and diagrams. It is responsive for desktop and mobile, and was tested with axe-core (WCAG 2 A/AA, 0 violations).

| File | Purpose |
| --- | --- |
| `index.html` | Page content |
| `styles.css` | Base layout, typography, components |
| `glass.css` | Glassmorphism + illustration layer |
| `final.css` / `final.js` | Footer, back-to-top, accessibility fix, 404, print |
| `script.js` | Mobile menu, scroll effects, custom cursor, animated network background |
| `assets/` | SVG illustrations, diagrams and favicon |
| `404.html` | Custom not-found page |

## Run locally
Open `index.html` in a browser, or run `python -m http.server` and visit http://localhost:8000.
